# Brasa & Mesa

Landing page de restaurante desenvolvida com HTML, CSS e JavaScript, sem backend e sem etapa de build.

## Recursos

- Layout responsivo e animações com suporte a movimento reduzido.
- Cardápio com filtros por categoria e detalhes dos pratos.
- Menu móvel acessível.
- Formulário demonstrativo de reserva, sem transmissão de dados.

## Executar

Abra `index.html` no navegador. Fontes e fotografias são carregadas do Google Fonts e Unsplash e precisam de internet.

## Publicação

GitHub Pages configurado para servir a raiz da branch `main`. Alterações em `index.html` são publicadas automaticamente.

## Conteúdo demonstrativo

Marca, cardápio, preços e horários são ilustrativos. O formulário não efetua reservas reais.
